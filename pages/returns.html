Returns Policy

Simple return requests for eligible orders

If something is wrong with your order, share your order ID and a short explanation so the request can be reviewed quickly.

Return Window

Return requests should be submitted within 7 days after delivery.

Item Condition

Returned items should be unworn, clean, and in original condition so they can be reviewed properly.

How To Start

  • Open WhatsApp support.
  • Share your order ID and the product name.
  • Describe the issue clearly and attach photos if needed.

Review Process

Each request is reviewed individually. Approval depends on condition, timing, and the reason for the return.

Before requesting a return

Please confirm you selected the correct size and product option at checkout. If you need help, our support team can review the order details with you.
